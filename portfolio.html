Projetos

PRD_SAC

Sistema de atendimento (SAC) full stack, com robô em Python/Selenium para automatizar o ciclo de atendimento e um pipeline de dados para relatórios e métricas.

PythonSeleniumPandas PHPPostgreSQLHTML/CSSRender

Problema

Simular uma operação de atendimento (SAC) com ciclo completo: abertura do atendimento, interação em chat, conclusão e expiração automática — sem intervenção manual no acompanhamento.

Solução

Aplicação web full stack (PHP + PostgreSQL para o backend/dados, HTML/CSS na interface) combinada a um robô em Python com Selenium, responsável por automatizar interações e validar o fluxo de ponta a ponta.

Automação

O robô usa WebDriverWait e espera explícita para lidar com latência, carregamento de página e cold start do servidor hospedado em nuvem (Render).

Engenharia de dados

  • Extração de dados tabulares do sistema
  • Limpeza e normalização com Pandas
  • Processamento em memória
  • Geração de relatórios e métricas de acompanhamento

Arquitetura

Usuário→ Sistema Web→ Banco de Dados→ Python / Selenium→ Pandas→ Relatórios
